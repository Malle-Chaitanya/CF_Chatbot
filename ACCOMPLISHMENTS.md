### Email Matching System
```
from app.models.teams import get_team_by_member_email

Approach:
- Case-insensitive lookup
- Check leads first
- Check members second
- Return "Unassigned" if not found
- Performance: O(n) optimized
```

### Caching Strategy
```
Cache Duration: 1 hour
Storage: React state
Key: date_range_hash
Hit Rate: Expected 70-80%
Memory: ~1MB per 100 results
```

### Data Aggregation
```
Process:
1. Fetch traces from Langfuse (paginated)
2. Extract user_email from metadata
3. Match email to team
4. Count questions
5. Calculate statistics
6. Return aggregated data
```
