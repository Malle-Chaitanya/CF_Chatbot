## Usage in Code

```python
from app.models.teams import get_team_by_member_email

# Get team for a specific email
team = get_team_by_member_email("santosh@cloudfuze.com")
# Returns: "Content"

team = get_team_by_member_email("ankit@cloudfuze.com")
# Returns: "Messaging & Email"

team = get_team_by_member_email("unknown@example.com")
# Returns: "Unassigned"
```

## Notes

- All emails are stored in lowercase format for case-insensitive matching
- Team leads are included in the member count
- If a user's email is not found in any team, they are marked as "Unassigned"
- Each team has a unique color for visual distinction in dashboards
- Email format is standardized as: `firstname.lastname@cloudfuze.com` or `firstname@cloudfuze.com`
